One-line: the official SRSS seal, locked up with the bilingual school name — use it for any masthead, letterhead or footer.

```jsx
<Crest size={64} lockup="full" tone="onNavy" src="assets/logo-srss-crest.png" />
<Crest size={40} lockup="mark" />
```

The crest artwork is `assets/logo-srss-crest.png` and must never be redrawn, recoloured, stretched or rotated. Minimum clear space equals half the crest diameter. Below 40px use `lockup="mark"` — the ring type stops being legible.
