One-line: the SRSS text CTA — label, arrow, and a gold rule that grows to full width on hover.

```jsx
<ArrowLink>Arrange a visit</ArrowLink>
<ArrowLink tone="onNavy" icon="arrow-up-right">Read the story</ArrowLink>
```

Always pair with a `Button variant="primary"` — gold fill carries the main action, ArrowLink the alternative. Use `arrow-up-right` for stories and off-site links, `arrow-right` for navigation within the site.
