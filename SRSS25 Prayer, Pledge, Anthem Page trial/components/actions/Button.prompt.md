One-line: the SRSS action button — gold fill for the one primary action, outline/ghost for everything else.

```jsx
<Button icon="arrow-right">Explore SRSS</Button>
<Button variant="outline">Download prospectus</Button>
<Button variant="outline-ink" size="sm">Learning</Button>
```

Variants: `primary` (gold, navy label), `outline` (gold hairline — navy grounds only), `outline-ink` (navy hairline — cream grounds), `ghost`, `solid` (navy fill). Sizes sm/md/lg. Corners are 4px, never pill. Hover lightens the gold and nudges a trailing arrow 3px right.
