One-line: 20px square checkbox, gold when checked, with an optional description line.

```jsx
<Checkbox label="I would like a guided campus tour"
  description="Tours run Tuesdays and Thursdays, 9–11am." />
```

Square with a 4px radius (radio-style circles are not part of this system). The check glyph is `Icon name="check"` in navy on gold.
