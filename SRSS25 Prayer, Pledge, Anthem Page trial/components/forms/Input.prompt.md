One-line: labelled text field with an uppercase micro-label and a gold focus ring.

```jsx
<Input label="Child's full name" required placeholder="As per birth certificate" />
<Input label="Email" error="Enter a valid email address" />
```

Labels are Poppins 11px uppercase with 0.14em tracking — the same treatment as `Eyebrow`. Focus is a gold border plus a 3px gold glow; never a blue browser ring.
